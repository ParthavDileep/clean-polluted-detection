# 🌍 Clean vs Polluted Area Detection Using AI

An AI-powered deep learning system that automatically detects whether a street area is **clean** or **polluted** from images using **MobileNetV2** transfer learning.

## 🎯 Project Overview

This project uses **Convolutional Neural Networks (CNN)** with transfer learning (MobileNetV2) to classify street images as either **clean** or **polluted**. The system can help municipalities, smart cities, and environmental agencies monitor urban cleanliness automatically.
